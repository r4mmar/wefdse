Here’s a quick way to install Brave via the terminal on Lubuntu (which uses the standard APT package manager like Ubuntu).

### Add Brave’s repository and import the GPG key

```bash
# Install prerequisites if not already present
sudo apt update
sudo apt install -y curl gnupg

# Add Brave’s GPG key
curl -fsSL https://brave-browser-rpm-release.s3.brave.com/brave-browser-repo.asc \
  | sudo gpg --dearmor -o /etc/apt/keyrings/brave-browser-archive-keyring.gpg
```

> Note: The command above uses the **Debian/Ubuntu** key URL. If you get an error, use the Ubuntu-specific key:
> ```bash
> curl -fsSL https://brave-browser-rpm-release.s3.brave.com/brave-browser-archive-keyring.gpg \
>   | sudo gpg --dearmor -o /etc/apt/keyrings/brave-browser-archive-keyring.gpg
> ```

### Add the repository

```bash
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/brave-browser-archive-keyring.gpg] https://brave-browser-rpm-release.s3.brave.com/ stable main" | \
  sudo tee /etc/apt/sources.list.d/brave-browser-release.list
```

> If you encounter issues, try using the **Debian/Ubuntu** repository URL directly:
> ```bash
> echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/brave-browser-archive-keyring.gpg] https://brave-browser-rpm-release.s3.brave.com/ stable main" | \
>   sudo tee /etc/apt/sources.list.d/brave-browser-release.list
> ```

### Install Brave

```bash
sudo apt update
sudo apt install -y brave-browser
```

### Launch Brave

```bash
brave-browser
```

**Alternative (simpler, but not via official repo):**  
If you prefer a one-line install without adding a repo:

```bash
wget -qO- https://brave-browser-rpm-release.s3.brave.com/brave-browser-auto-installer.sh | sudo bash
```

This script adds the repo and installs Brave automatically.
